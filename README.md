# Anonymous Pro — сайт-образец шрифта

Одностраничный сайт о моноширинном шрифте Anonymous Pro в стиле интерфейсов Windows 90-х: окна «Блокнот» и Paint, пиксельные курсоры, серые кнопки. Сверстан на чистом HTML и CSS по макету из Figma.
